Computer vision · multi-label classification

Movie genres from posters, several at a time

A Flask web app where you upload a movie poster and get back its predicted genres, each with a confidence score, from a convolutional neural network trained in TensorFlow/Keras. Multi-label: one poster can belong to several genres.

  • Python

LLM application · AWS

AI meeting summarizer and action tracker

An AI meeting assistant that turns transcripts into concise summaries, key decisions and actionable tasks: a React front end over a FastAPI service that calls the OpenAI API, deployed on AWS.

Cut manual meeting-note preparation by 80% across 200+ test meetings.

  • Python
  • FastAPI
  • React
  • OpenAI API
  • AWS

Document AI · serverless

Cloud-based document intelligence system

A serverless document-processing pipeline that extracts structured information from invoices and PDFs with AWS Textract and Lambda, with a Flask layer on top.

94% field-level extraction accuracy across 2,000+ documents.

  • Python
  • AWS S3
